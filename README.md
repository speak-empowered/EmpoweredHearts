# Empowered Hearts Foundation Website

A responsive, static nonprofit website for Empowered Hearts Foundation.

## Built for
- GitHub repository hosting/version control
- Netlify continuous deployment
- Mobile, tablet, and desktop viewing
- Accessible navigation and semantic HTML
- Givebutter donation conversion

## Files
- `index.html` — site content and structure
- `styles.css` — responsive styling
- `assets/logo.png` — Foundation horizontal logo
- `assets/foundation-mark.png` — Foundation artwork/mark
- `assets/nathan-mitchell.png` — Director headshot

## Publish to GitHub
Create a new public repository, for example:

`empowered-hearts-foundation`

Upload the contents of this folder to the repository root. GitHub's current documentation supports creating a repository and uploading an existing group of files through the web interface.

## Publish to Netlify
In Netlify, choose **Add new project → Import an existing project**, select GitHub, authorize access to the repository, and publish. Because this is a static site, no build command or publish directory is required beyond the repository root.

Once connected to GitHub, Netlify can automatically redeploy the site whenever changes are pushed to the production branch.
